# Задачи по SQL (схема магазина)

Решай по порядку. Сначала попробуй сам минимум 15 минут — потом подглядывай в `04_solutions.sql`.
Правило: каждый запрос должен возвращать осмысленный результат, а не просто «что-то вывелось».

---

## Уровень 1 — JOIN-ы (база)

1. Выведи все товары вместе с названием их категории (INNER JOIN).
2. Выведи все заказы: id заказа, имя клиента, статус, дата.
3. Выведи ВСЕ товары, даже те, у которых категория не указана, вместе с категорией (LEFT JOIN).
   *(Подсказка: в данных такой товар есть — сначала добавь его: `INSERT INTO products (name, price, stock) VALUES ('Тестовый товар', 10.00, 1);`)*
4. Найди товары, которые ещё ни разу не покупали (JOIN + условие IS NULL).
5. Выведи клиентов, у которых нет ни одного заказа (LEFT JOIN + IS NULL).
6. Для каждой позиции заказа покажи: id заказа, имя клиента, название товара, количество, цену позиции (quantity × unit_price).
7. Выведи заказы, где есть товар из категории «Книги» (три таблицы: orders → order_items → products → categories).
8. Найди клиентов из Минска, покупавших электронику. Убери дубликаты клиентов.

## Уровень 2 — агрегаты и GROUP BY

9. Посчитай количество заказов у каждого клиента (включая тех, у кого 0 заказов).
10. Выведи суммарную выручку по каждому статусу заказа.
11. Найди топ-3 самых продаваемых товара по количеству штук (по оплаченным заказам: status IN ('paid','shipped','delivered')).
12. Для каждого товара покажи: сколько раз покупали, общее количество штук, суммарная выручка. Только товары, которые покупали.
13. То же самое, но включи и непроданные товары (LEFT JOIN), выручка NULL замени на 0 (COALESCE).
14. Найди средний чек (средняя сумма заказа) по каждому городу.
15. Выведи категории, суммарная выручка которых больше 2000.
16. Для каждого клиента посчитай: всего заказов, сколько из них доставлено, суммарная выручка по доставленным.

## Уровень 3 — подзапросы

17. Найди самый дорогой товар (без ORDER BY + LIMIT — через подзапрос с MAX).
18. Найди товары, дороже средней цены по своей категории (коррелированный подзапрос).
19. Выведи клиентов, чей суммарный объём покупок больше среднего суммарного объёма по всем клиентам.
20. Найди клиентов, которые покупали «Наушники Sony WH-1000XM5», но никогда — «Чистый код».
21. Выведи последний заказ каждого клиента (подзапрос с MAX(created_at)).

## Уровень 4 — оконные функции

22. Пронумеруй заказы каждого клиента по дате (ROW_NUMBER OVER (PARTITION BY ... ORDER BY ...)).
23. Выведи последний заказ каждого клиента через оконную функцию (сравни с задачей 21 — почувствуй разницу).
24. Для каждого заказа покажи его сумму и ранг (RANK) среди всех заказов.
25. Накопительная выручка по датам заказов (SUM(...) OVER (ORDER BY ...)).
26. Для каждого товара покажи его цену и разницу со средней ценой его категории (OVER (PARTITION BY category_id)).

## Уровень 5 — на подумать (как на собеседовании)

27. Напиши запрос: имя клиента + сумма его самой крупной покупки. Если покупок нет — 0.
28. Найди товары, цена которых изменилась: unit_price в order_items не совпадает с текущей price.
29. Пересчитай total_amount для каждого заказа на основе order_items и обнови таблицу orders (UPDATE + подзапрос).
30. Удали все отменённые заказы вместе с их позициями (в правильном порядке из-за внешних ключей).
